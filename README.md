# Car Atlas · 자동차 친구들

3~10세가 한국 브랜드의 세단과 SUV를 사진으로 살펴보는 작은 도감이다. HTML/CSS/JS와 Node 표준 라이브러리만 사용한다. 기존 Sea/Dino/Insect Atlas는 수정하지 않는다.

## 열기

- 비공개 도감: https://car-atlas-kids.ochresquid4096.chatgpt.site (소유자 계정으로 접근)
- Windows: `start-car-atlas.cmd` 실행. Node.js가 필요하다.
- 터미널: `npm test`, `npm run build`, `npm start` 순서.
- 로컬 주소: http://127.0.0.1:8042
- 다른 서비스가 8042를 사용하면 해당 서비스를 확인한 뒤 포트를 조정한다. 실행 스크립트는 기존 프로세스를 종료하지 않는다.

## MVP 범위

16개 차종과 재사용 조건을 확인한 사진 28장. 이름/별칭 검색, 세단/SUV/브랜드 필터, 브라우저별 좋아하는 차 저장, 상세와 확대 보기, 지원 브라우저의 한국어 이름 읽기를 제공한다. 이름 읽기는 설치된 운영체제 음성에 따라 달라지며 마이크를 사용하지 않는다.

차종: 쏘나타, 아이오닉 6, 팰리세이드, 코나, 싼타페, K5, K8, EV4, 쏘렌토, EV3, 스포티지, EV5, G80, GV70, GV80, 액티언.

기준일은 2026-10-28. 외형은 풀체인지/페이스리프트로 구분하고 연식·색상·일반 트림·휠만 바뀐 경우 새 외형으로 세지 않는다. 최신 외형 사진을 검증하지 못한 아반떼·투싼·그랜저·토레스는 첫 MVP에서 제외했다. 단종/발표만 된 차·과거 세대 탐색·가격 및 제원 비교·퀴즈는 포함하지 않는다.

## 자료와 사진

- `data/cars.js`: 짧은 어린이 설명, 외형 기준, 공식 자료 링크.
- `data/image-sources.json`: Commons 원본 페이지, 저자, 파일별 라이선스, 다운로드 URL, 외형/시장 사양, 공개/원본 SHA-256과 치수, 웹용 축소 기록.
- `assets/cars/`: 긴 변 1400px 이하의 공개용 JPEG. CC BY-SA와 CC0 조건은 사진별로 다르다. 앱 상세와 확대 보기에 저자·이용 조건·원본 링크를 표시한다.
- 일부 사진은 미국/호주/태국/전시장 등 해외 사양이다. 같은 현행 차체 외형의 사진으로 쓰되, 국내 사양의 모든 옵션·배지와 같다고 주장하지 않는다. GV80의 국내 최신 연식 후면 배지 차이도 기록했다.
- K5, GV70, 싼타페, EV5는 현재 한 장씩이고 나머지는 두 장씩이다. 한 장만 있는 차의 뒤 사진을 꾸며 넣지 않는다.
- 원본·탈락본·조사와 검토 기록은 무시되는 `work/`에 보존한다. 기록 자체가 제조사나 전문가의 감수를 뜻하지 않는다.

## 검증과 빌드

`node scripts/verify.mjs`는 선정 16종, ID, 필수 설명/외형/출처, 사진 라이선스 필드·원본과 구분한 공개본 해시, 별칭/복합 검색, 손상된 저장값 복구를 검사한다. 사진의 자동차 정체성 자체를 자동 판정하지 않는다.

`node scripts/build.mjs`는 공개 파일 목록으로 `dist/`만 조립하고 공개 카탈로그를 직렬화한다. `work/`, 제작 원본, 내부 스크립트·문서·로컬 경로는 공개하지 않는다. `dist/` 외부는 정리하지 않는다.

PC와 390/320px 모바일 화면, 검색/필터/빈 상태/저장 유지/상세/사진 이동/Escape/포커스/직접 링크를 브라우저에서 확인한다. 로컬 서버는 `dist/`만 제공하고 루프백에만 바인딩한다.

## 이어서 작업할 때

이 폴더가 독립 프로젝트다. 원래 ChatGPT 프로젝트의 `sources/`는 읽기 전용이다. `docs/codex-handoff.md`부터 읽고 현재 파일/Git 상태를 확인한다. 배포 ID는 `.openai/hosting.json`에 있으며 새 Site를 중복 생성하지 않는다.
