# 탈것 아틀라스 · 땅부터 우주까지

3~10세가 자동차·중장비·항공기·기차·배·농기계·자전거·우주 탈것의 모습과 하는 일을 사진으로 살펴보는 도감이다. 한국차와 대표 외산 세단/SUV, 여러 나라의 실제 탈것 예시를 소개한다. HTML/CSS/JS와 Node 표준 라이브러리만 사용한다. 기존 Sea/Dino/Insect Atlas는 수정하지 않는다.

## 열기

- 공개 도감: https://jjapshe.github.io/car-atlas/
- 개인 저장소: https://github.com/JJapShe/car-atlas
- 이전 비공개 미리보기: https://car-atlas-kids.ochresquid4096.chatgpt.site (소유자 계정으로 접근)
- Windows: `start-car-atlas.cmd` 실행. Node.js가 필요하다.
- 터미널: `npm test`, `npm run build`, `npm start` 순서.
- 로컬 주소: http://127.0.0.1:8042
- 다른 서비스가 8042를 사용하면 해당 서비스를 확인한 뒤 포트를 조정한다. 실행 스크립트는 기존 프로세스를 종료하지 않는다.

## 앱으로 설치

공개 도감 아래의 ‘바탕화면에 설치’를 누른다. Chrome/Edge가 설치 준비를 마치면 기본 설치 창이 열리며, 지원하지 않는 브라우저나 아직 준비 전인 경우 안내를 제공한다. PC에서는 주소창의 설치 아이콘/브라우저 앱 설치 메뉴도 사용할 수 있다. 설치 후 주소창 없는 별도 창으로 실행한다. 기존 설치와 하트 저장을 유지하기 위해 주소/앱 ID/저장 키는 계속 car-atlas를 사용한다. 표시 이름은 탈것 아틀라스이며, 이미 설치한 앱의 이름 갱신 시점과 확인 창은 Chrome이 관리한다. 실제 설치는 사용자가 브라우저의 설치 창에서 완료한다.

`manifest.webmanifest`는 GitHub Pages의 `/car-atlas/` 안에서만 시작하고 동일한 앱 ID를 유지한다. 기존 SVG 로고에서 192/512px PNG 아이콘을 만들었으며 `install.js`가 설치 이벤트·취소·오류·설치 완료·독립 앱 창 상태를 처리한다. 앱 화면과 사진은 인터넷 연결이 필요하다. 오프라인 저장이나 서비스 워커를 추가하지 않아 새 배포의 사진/카탈로그를 기존 네트워크 흐름으로 불러온다.

## 도감 범위

여러 나라의 실제 탈것 120종을 소개한다. 이름/별칭 검색, 13개 종류 필터와 전체 보기, 승용차 브랜드 필터, 브라우저별 좋아하는 친구 저장, 상세와 확대 보기, 지원 브라우저의 한국어 이름 읽기를 제공한다. 이름 읽기는 설치된 운영체제 음성에 따라 달라지며 마이크를 사용하지 않는다. 현재 120종, 사진 213장이다. 목록에 사진 장수를 표시하며 상세의 갤러리와 확대 보기에서 사진을 넘겨 볼 수 있다. 사진 수와 해시는 검증 명령의 현재 출력으로 확인한다.

중장비 10종: 굴착기, 불도저, 휠로더, 백호 로더, 스키드 스티어 로더, 모터 그레이더, 로드 롤러, 아스팔트 포장기, 덤프트럭, 콘크리트 믹서 트럭.

특수 중장비 18종: 이동식 크레인, 타워크레인, 크롤러 크레인, 콘크리트 펌프카, TBM 터널 굴착기, 버킷휠 굴착기, 광산용 대형 트럭, 산림 수확기, 걷는 굴착기, 드래그라인 굴착기, 트렌처, 스크레이퍼, 리치스태커, 회전식 시추기, 텔레핸들러, 도로 절삭기, 스트래들 캐리어, 굴절식 덤프트럭. 이 그룹은 법적 분류가 아닌 어린이용 탐색 묶음이다.

회전익기 6종: 작은 헬리콥터 R44, 구조 헬리콥터 H145, 치누크, Ka-32, 오토자이로, 하늘 크레인 S-64. 고정익기 6종: A320, ATR 72, 세스나 172, 글라이더, 비버 수상기, C-130. 각 2장씩이며 항공기는 기존 ID와 사진을 유지한다.

장비와 항공기는 최신 판매 모델을 나열하는 방식이 아니라 종류와 역할을 소개한다. 첫 화면에는 작은 헬리콥터를, 목록에서는 새 분류를 번갈아 만난다. 기존 중장비와 승용차도 그대로 탐색한다. 장비 사진은 사진 속 제조사·모델·부착 장치·촬영 상태를 기록하며 일반 승용차의 세대 변경과 섞지 않는다.

한국 승용차 초기 자료 기준일은 2026-10-28, 외산 대표차 추가 확인일은 2026-10-30. 승용차 외형은 풀체인지/페이스리프트로 구분하고 연식·색상·일반 트림·휠만 바뀐 경우 새 외형으로 세지 않는다. 최신 외형 사진을 검증하지 못한 아반떼·투싼·그랜저·토레스는 첫 MVP에서 제외했다. 한국차 초기 선정 기준을 유지한다. 해외 대표차에는 이전 세대 사진 예시도 포함하며 외형·시장·연도를 따로 기록한다. 가격 및 제원 비교·퀴즈는 포함하지 않는다.


## 다양한 탈것 확장 · 2026-10-30

이번에 64종과 사진 116장을 추가했다. 합계 120종/213장이다. 새 분류는 기차 8종, 배 11종, 버스·특수차 15종, 농기계 4종, 자전거·오토바이 6종, 기구·비행선 2종, 우주 탈것 4종이다. 기존 중장비는 눈 정리차와 항만 컨테이너 크레인을 더해 각각 11종/19종이다. 세단 12종/SUV 16종과 회전익·고정익 각6종을 함께 제공한다.

외산차 12종: 모델 3, 3시리즈, E클래스, 코롤라, 시빅, 캠리, 모델 Y, RAV4, CR-V, X5, GLC, 디펜더 110. RAV4는 5세대 예시이며 최신형이라고 표시하지 않는다. 캠리는 중국 판매형, BMW 3시리즈는 루마니아 경찰차 도장 예시다. 모든 외산차가 한국 최신 판매 사양이라는 뜻은 아니다. 풀체인지/페이스리프트로 외형을 구분하고 세부 트림과 사진 시점은 사진별로 기록한다.

`data/vehicles.js`, `data/vehicle-image-sources.json`과 `assets/transport/`가 새 진입점이다. 승용 사진은 기존 `assets/cars/`, 중장비 사진은 `assets/machines/`를 재사용한다. 기차·배 등은 `appearance.change=vehicle`로 종류/역할을 설명한다. 우주왕복선·아폴로 달 탐사차 등 과거 실제 탈것도 포함한다. 연구용 잠수정의 유인 Alvin/무인 AsterX는 사진별로 구분한다.

Terra/Luna가 자료·권리·입력/공개본 해시·사진 정체성을 나누어 조사했고 부모가 전량 콘택트시트와 화면을 확인했다. KTX 후보 중 SRT 도장 사진과 알아보기 어려운 과거 목화 수확기 사진은 제외했다. RAV4 후면 추가 후보도 부분변경 일치 여부가 불확실하여 제외했다. 쓰레기 수거차 보강 사진은 Commons 영상의 허용된 포스터 정지 이미지다. 사진별 출처·저자·이용 조건은 상세/확대 보기에 표시한다. 조사와 원본·탈락본은 `work/expansion-20261030/`에만 보존한다.

기존 56개 ID와 97장 사진 해시, `/car-atlas/` 주소, 설치 앱 ID와 하트 저장 키를 유지한다. 버스 검색에 경찰차가 섞이던 결합 분류명 검색을 고쳤으며 별칭/분류/브랜드/혼합 저장 복구를 검증한다. 작은 화면에서 14개 분류 버튼을 줄바꿈하고 새 첫 문장의 가로 넘침을 수정했다. 최종 공개 파일은 222개, 캐시 버전은 `20261030-world-1`이다.

## 자료와 사진

- `data/cars.js`: 짧은 어린이 설명, 외형 기준, 공식 자료 링크.
- `data/aircraft.js`: 회전익기와 고정익기의 짧은 구조·역할 설명, 관찰 단서, 공식 자료 링크.
- `data/aircraft-image-sources.json`과 `assets/aircraft/`: 항공기 12종×2장, 실제 기체/세부 형식/관찰 시점/권리와 입력·공개본 해시.
- `data/machines.js`: 중장비의 짧은 역할 설명, 관찰 단서, 제조사 자료 링크.
- `data/image-sources.json`: Commons 원본 페이지, 저자, 파일별 라이선스, 다운로드 URL, 외형/시장 사양, 공개/원본 SHA-256과 치수, 웹용 축소 기록.
- `data/machine-image-sources.json`: 중장비 사진별 실물 예시·시점·부착 장치·저자·라이선스·원본 및 공개본 해시.
- `assets/cars/`: 긴 변 1400px 이하의 공개용 JPEG. CC BY-SA와 CC0 조건은 사진별로 다르다. 앱 상세와 확대 보기에 저자·이용 조건·원본 링크를 표시한다.
- `assets/machines/`: 핵심 작업부가 보이는 장비 사진. 사진 속 예시를 최신 모델이나 한국 사양으로 단정하지 않는다. 같은 종류의 서로 다른 실물 모델·부착 장치도 사진별로 구분한다.
- 일부 사진은 미국/호주/태국/전시장 등 해외 사양이다. 같은 현행 차체 외형의 사진으로 쓰되, 국내 사양의 모든 옵션·배지와 같다고 주장하지 않는다. GV80의 국내 최신 연식 후면 배지 차이도 기록했다.
- 한국차의 K5, GV70, 싼타페, EV5와 외산 RAV4는 현재 한 장씩이다. 한국차 나머지12종과 외산차 나머지11종은 두 장씩이다. 한 장만 있는 차의 뒤 사진을 꾸며 넣지 않는다.
- 원본·탈락본·조사와 검토 기록은 무시되는 `work/`에 보존한다. 기록 자체가 제조사나 전문가의 감수를 뜻하지 않는다.

## 검증과 빌드

`node scripts/verify.mjs`는 기존 승용 16종 보존, 추가 장비 전체 연결, ID, 짧은 설명/외형·종류/출처, 사진 라이선스 필드·원본과 구분한 공개본 해시, 별칭/복합 검색, 손상된 저장값 복구를 검사한다. 장비를 세단으로 잘못 검색하지 않는지, 승용차와 장비의 하트를 함께 복구하는지도 검사한다. 동일 원본을 잘라 사진 장수를 늘리는 중복도 해시로 검사한다. 사진의 정체성 자체를 자동 판정하지 않는다.

`node scripts/build.mjs`는 공개 파일 목록으로 `dist/`만 조립하고 공개 카탈로그를 직렬화한다. `manifest.webmanifest`, `install.js`, 앱 아이콘도 공개 목록에 포함한다. `work/`, 제작 원본, 내부 스크립트·문서·로컬 경로는 공개하지 않는다. `dist/` 외부는 정리하지 않는다.

PC와 390/320px 모바일 화면, 검색/필터/빈 상태/저장 유지/상세/사진 이동/Escape/포커스/직접 링크를 브라우저에서 확인한다. 로컬 서버는 `dist/`만 제공하고 루프백에만 바인딩한다.

## GitHub Pages

`main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 Node.js 24에서 검증과 빌드를 실행한 뒤 `dist/`만 Pages에 배포한다. 별도 패키지 설치는 필요하지 않는다. 저장소에는 앱 소스와 선정된 사진, 출처와 라이선스 기록을 보존하며 `work/` 원본·탈락본·로그·로컬 검증 자료는 올리지 않는다.

Actions 성공 뒤 공개 주소의 실제 카탈로그/사진과 PC·모바일 화면을 확인한다. 이후 공개 배포의 기본 대상은 GitHub Pages이며, 이전 Sites 미리보기의 접근 범위는 유지한다.

## 이어서 작업할 때

이 폴더가 독립 프로젝트다. 원래 ChatGPT 프로젝트의 `sources/`는 읽기 전용이다. `docs/codex-handoff.md`부터 읽고 현재 파일/Git 상태를 확인한다. 공개 배포는 `JJapShe/car-atlas`의 GitHub Pages를 사용한다. `.openai/hosting.json`은 기존 비공개 미리보기의 ID이며 새 Site를 중복 생성하지 않는다.
