## 바탕화면 설치 설정 · 2026-10-28

사용자가 바탕화면 설치 기능 준비를 요청했다. manifest.webmanifest(상대 id/start_url/scope, standalone, 한국어 이름), 기존 SVG를 렌더링한 192/512 PNG, install.js와 페이지 하단 설치 영역/안내 dialog를 추가했다. 설치 대기 이벤트가 있으면 사용자 클릭으로 브라우저 기본 설치 창을 열고, 없으면 Chrome/Edge/모바일 설치 안내를 보여 준다. 사용자의 PC에 실제 설치 완료를 대신 실행한 것은 아니다.
